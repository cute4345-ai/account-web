# 個人帳戶｜ 畫面前端示範

依 `design1/網頁端` 的 01–27 霧藍版參考圖製作，沿用核定登入首頁。使用原生 HTML/CSS/JavaScript；不需要安裝套件或外部帳戶。

## 預覽

可直接開啟 `index.html`；圖示改以 img 載入提供的 SVG，支援直接開檔。也可在工作區根目錄執行 `./preview.ps1`，瀏覽 `http://127.0.0.1:8000`。

示範帳號 **demo**、密碼 **demo1234**；安全問題答案 **小王子**；示範證號 **DEMO-ID-001**。可從「流程示範」按「以示範帳戶進入」，或使用登入表單。

「流程示範」入口在桌面左下、手機頁首。選單可直接預覽 01–27 狀態，也可重置本次示範。預覽會設定示範帳戶的卡片及商家狀態；不是變更真實帳戶或審核結果。

## 可操作流程

- 登入：帳密檢查、密碼顯示切換、必填與空白輸入提示。
- 註冊：六欄表單、重複證號／帳號提示、成功後重新登入。示範證號可使用 DEMO-ID-002，不必輸入真實個資。
- 找回密碼：帳號識別、安全問題、答案比對、兩次新密碼、完成及重新登入。
- 主畫面：綁卡／未綁卡、餘額顯示切換、個人交易及日期查詢／清除／無結果。新註冊帳戶的交易為空，示範餘額為 0。
- 商家：未申請、資料表單、送出後審核中。審核不會自動通過；預覽 16 查看已核准示範，17 可查詢獨立收款紀錄。
- 商家刷卡收款：在已核准商家頁面輸入付款金額（新台幣整數）及付款項目，開始收款後等待付款人插卡。按「模擬付款人插卡」後自動結帳，直接顯示處理中與成功結果，商家無須再次確認付款；可測試失敗、重試、返回修改或取消。僅模擬成功時新增一筆含付款項目的收款紀錄，取消、失敗、處理中離頁均不新增。沒有實際扣款或入帳。
- 卡片：資料、密碼變更／舊密碼檢查、遺失註銷、未綁卡、插卡、讀卡中、確認、完成。註銷不刪除登入帳戶。
- 模擬讀卡：先按「模擬插入示範卡片」，等待三秒，再按「確認綁卡」。取消會清除計時，避免稍後跳回確認畫面。
- 登出：確認區塊不封鎖導覽，可直接點其他功能離開；選「否」保留登入並返回主畫面。選「是」清除本次示範登入狀態，再次進入須重新登入。沒有「重新開啟登出確認」按鈕。
- 版型：桌面導覽可收合；手機採選單、單欄及逐筆交易資料，保留所有欄位名稱。

## 程式與素材

- `index.html`：核定登入首頁的 HTML、共用頁首、流程預覽入口、原生 dialog。
- `style.css`：核定登入首頁的配色、背景、面板及 RWD。
- `account.css`：02–27 共用表單、導覽、資料表、卡片、狀態視窗及手機排版。
- `app.js`：Hash 路由、表單及示範狀態。使用者輸入輸出為 HTML 時有跳脫處理。
- `assets/icons/`：從使用者素材複製的 SVG，store.svg 統一小寫；補繪 card-reader.svg，原始素材不改動。導航與眼睛直接使用 img 顯示 SVG，色彩由 CSS filter 控制。

沒有提供獨立背景與光線素材，因此依原規劃用 CSS 製作；沒有把參考圖當背景或把文字合成圖片。各參考圖的頁首／外框略有差異，目前採一致的共用版型；字形、細微光斑與提供的 SVG 造型仍與原圖不同。

## 資料及功能邊界

這是記憶體流程示範。帳戶、密碼、安全答案及申請資料只存在目前分頁的 JavaScript 記憶體；不使用 cookies、localStorage 或 sessionStorage，不會傳送到後端。重新整理或按「重置示範」就回復初始資料。已修改的示範密碼只在本次頁面有效。

本次未連接資料庫、正式身分驗證、金流、商家審核或讀卡設備。原圖 10/11 對 T0007 的日期不同，實作採 10 的 2026-11-04，維持日期查詢的資料一致性。

收款介面依新增需求延伸參考圖 16，保留既有商家資訊，在下方加入收款表單；參考圖 17 的收款表格增加付款項目與付款人欄位。正式串接時，付款人識別、付款授權、金額與卡片有效性、扣款及入帳結果必須由讀卡服務與後端決定，不能採用前端模擬狀態。示範成功紀錄僅暫存在本分頁，重新整理清除。

商家模擬收款成功後，主頁可用餘額會累加相同金額，主頁交易紀錄也會同步顯示相同流水號、付款人與付款項目，支援日期查詢。三個畫面共用目前帳戶的成功收款資料；失敗、取消、處理中離頁與重複插卡事件不會重複增加餘額或交易。示範帳戶初始餘額為 NT$ 12,580，新註冊帳戶初始餘額為 0。

尚未進行實體手機、虛擬鍵盤、密碼管理器、iOS Safari、Firefox、正式後端或資安測試。
